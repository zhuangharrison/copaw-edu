### 2. 知识理解专家 (concept_master)

**老师讲的知识点听不懂？我用生活例子讲给你听！**

**用法：**
- "老师讲的惯性我没听懂"
- "什么是函数？"
- "这个概念怎么理解？"

**示例：**
```
你: 老师讲的"惯性"我没听懂

AI: 📊 理解诊断
让我帮你理解"惯性"！

【一句话说明】
惯性就是"懒"——物体都想偷懒，不想改变现状。

【生活类比】
想象坐公交车：
- 车突然启动 → 你向后倒（身体想保持静止）
- 车突然刹车 → 你向前倒（身体想保持运动）
这就是惯性！

【记忆口诀】
"惯性就是懒，不动懒得动，动懒得停"

✅ 现在请你用"公交车"的例子，解释一下什么是惯性？
```

**特点：**
- 用10岁孩子能懂的语言
- 生活类比 + 故事化讲解
- 学完后自动加入记忆系统

### 3. 错题管家 (mistake_master)

**智能管理你的错题本，长期追踪1-3年！**

**用法：**
- "记录错题：[题目]，我选了[答案]，正确答案是[答案]"
- "帮我分析这道错题"
- "我的错题统计"
- "今天复习哪些错题？"

**示例：**
```
你: 记录错题：解方程2x+5=13，我算的x=9，正确答案是x=4

AI: 📝 错题录入成功！

📊 自动分析
【学科】数学
【章节】一元一次方程
【错误类型】计算失误型

【错误原因】
你的解答：2x = 13 + 5 ← 错误！
正确解答：2x = 13 - 5 ← 移项要变号！

📚 名师精讲
【核心规则】移项要变号！
【口诀】"移项要变号，不变就错了"

🔄 举一反三
变式题1：3x - 7 = 8
变式题2：5 + 2x = 15

📂 已归档：数学 > 方程 > 一元一次方程 > 计算失误
📅 复习计划：明天、3天后、7天后
```

**6种错误分类：**
- 知识盲区型 → 补基础
- 概念混淆型 → 对比辨析
- 计算失误型 → 检查习惯
- 审题错误型 → 圈画关键词
- 方法错误型 → 归纳题型
- 粗心大意型 → 养成习惯

## 使用技巧

### 推荐做法

1. **完整描述问题**：把题目完整发给我
2. **说出你的理解**：告诉我你是怎么想的
3. **不懂就问**：哪里不清楚直接问
4. **坚持复习**：按复习计划执行

### 避免做法

1. **只求答案**：重要的是学会方法
2. **不复习**：记忆需要重复
3. **不记录错题**：错题是提升的关键

## 常见问题

**Q: 为什么不直接给我答案？**
A: 直接告诉你答案，下次遇到类似题目你可能还是不会。引导你思考，才能真正学会。

**Q: 复习计划是怎么安排的？**
A: 采用艾宾浩斯遗忘曲线，在最佳时间点提醒你复习：20分钟→1小时→1天→2天→4天→7天→15天→1月

**Q: 错题追踪多久？**
A: 支持1-3年长期追踪，帮你分析薄弱知识点，看进步趋势。

**Q: 多模态生成怎么用？**
A: 需要先配置API（如Seedance 2.0），在设置向导中选择配置多模态API。

**Q: 数据安全吗？**
A: 所有数据本地存储，不会上传到服务器。
