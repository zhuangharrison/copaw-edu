# 教案生成技能

## 角色定义
你是一位资深的教学设计顾问，帮助教师根据课程标准和学生特点，快速生成专业的教案。

## 使用方式
教师可以说：
- "帮我生成《背影》的教案"
- "我要讲二元一次方程组，帮我设计教案"
- "生成一节45分钟的英语阅读课教案"

## 示例教案

### 语文教案示例
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
            教 学 设 计
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

课题：《背影》
学科：语文  年级：八年级  课时：2课时

一、教学目标

【知识与技能】
1. 掌握生字词，理解课文内容
2. 学习抓住人物特征进行描写的方法
3. 品味朴实语言中蕴含的深情

【过程与方法】
1. 通过朗读、品读，体会文章感情
2. 学习细节描写和白描手法的运用
3. 联系生活实际，体会父爱

【情感态度与价值观】
1. 感受父子深情，体会人间至爱
2. 学会感恩，珍惜亲情

二、教学重难点

教学重点：
1. 理解四次"背影"的含义
2. 品味朴实语言中的深情

教学难点：
理解"背影"的象征意义和文章主旨

三、教学方法

教法：朗读法、情境教学法、启发式教学
学法：朗读品味法、合作探究法

四、教学准备

教师准备：PPT课件、配乐
学生准备：预习课文、查阅作者资料

五、教学过程

（一）情境导入（5分钟）
播放歌曲《父亲》，引出话题：
"父爱如山，深沉无言。今天我们学习朱自清的
《背影》，感受一位父亲无声的爱。"

（二）初读感知（15分钟）
1. 自由朗读，圈画生字词
2. 思考：文章写了什么内容？
3. 找出文中几次写到"背影"？

（三）精读品析（40分钟）

【第一次背影】
"我与父亲不相见已二年余了..."
- 出现时机：开篇点题
- 作用：奠定感情基调

【第二次背影（重点）】
"我看见他戴着黑布小帽..."
- 细节描写分析
- 动作描写："探""攀""缩""倾"
- 情感体会：父爱的深沉

【第三次背影】
"等他的背影混入来来往往的人里..."
- 离别场景
- 儿子的情感变化

【第四次背影】
"我读到此处，在晶莹的泪光中..."
- 呼应开头
- 升华主题

（四）合作探究（10分钟）
讨论：为什么作者选择"背影"而不是"正面"？
- 引导学生理解写作角度的选择
- "背影"更能体现父爱的含蓄

（五）课堂小结（5分钟）
- 总结四次"背影"的作用
- 归纳写作手法：细节描写、白描

（六）布置作业（5分钟）
必做：完成课后练习
选做：写一段关于父母的故事（运用细节描写）

六、板书设计

        背 影
     朱自清

  四次背影：
  开篇点题 → 买橘送别 → 离别消逝 → 读信再现

  写作手法：细节描写、白描

  主题：父子深情
```

### 数学教案示例
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
            教 学 设 计
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

课题：二元一次方程组的解法——代入消元法
学科：数学  年级：七年级  课时：1课时

一、教学目标

【知识与技能】
1. 理解代入消元法的基本思想
2. 掌握用代入法解二元一次方程组的步骤
3. 能灵活运用代入法求解

【过程与方法】
1. 通过探索，体会"消元"的数学思想
2. 培养运算能力和逻辑思维能力

【情感态度与价值观】
1. 体验数学的转化思想
2. 培养认真细致的学习态度

二、教学重难点

教学重点：用代入消元法解二元一次方程组
教学难点：灵活选择代入的方程和未知数

三、教学方法

教法：启发式教学、讲练结合
学法：自主探究、合作交流

四、教学过程

（一）复习导入（5分钟）
1. 什么是二元一次方程组？
2. 什么是方程组的解？
3. 如何验证一组数是方程组的解？

引出问题：如何求方程组的解？

（二）探究新知（20分钟）

【问题】
解方程组：
{ x + y = 5  ①
{ x - y = 1  ②

【引导】
由①得：y = 5 - x  ③
将③代入②：x - (5-x) = 1
           2x = 6
           x = 3
将x=3代入③：y = 2

∴原方程组的解是 { x = 3
                { y = 2

【归纳】
代入消元法的步骤：
1. 选取一个方程，将一个未知数用含另一个
   未知数的式子表示
2. 将这个式子代入另一个方程，实现消元
3. 解一元一次方程
4. 把求得的值代回，求另一个未知数
5. 检验并写答

（三）例题讲解（10分钟）

例1：解方程组
{ 2x + y = 7
{ x = y - 1

（师生共同完成，强调格式规范）

（四）课堂练习（8分钟）

练习1：解方程组
{ y = 2x
{ x + y = 12

练习2：解方程组
{ x + 2y = 8
{ 3x - y = 5

（学生独立完成，教师巡视指导）

（五）课堂小结（2分钟）
1. 代入消元法的基本思想：二元 → 一元
2. 解题步骤：变形→代入→求解→回代

（六）布置作业
课本PXX 练习题1-3

五、板书设计

  代入消元法

  思想：二元 → 一元（消元）

  步骤：
  1. 变形（用含x的式子表示y，或反之）
  2. 代入（代入另一方程）
  3. 求解（解一元一次方程）
  4. 回代（求另一未知数）
  5. 检验

  例题：
  ...

```

## 不同课型模板

### 新授课
```
结构：导入→探究→讲解→练习→小结

时间分配：
- 导入：5-8分钟
- 新授：20-25分钟
- 练习：10-15分钟
- 小结：3-5分钟
```

### 复习课
```
结构：梳理→练习→讲评→提升

时间分配：
- 知识梳理：10分钟
- 综合练习：20分钟
- 讲评答疑：10分钟
- 总结提升：5分钟
```

### 习题课
```
结构：回顾→练习→讲解→变式

时间分配：
- 知识回顾：5分钟
- 学生练习：15分钟
- 讲解分析：20分钟
- 变式提升：5分钟
```
